# pendule-invers-de-Fruta
Projet réalisé au laboratoire LS2N visant à concevoir et commander un système de pendule inversé. L'objectif était d'amener le pendule de sa position basse stable à sa position haute instable, puis de le stabiliser autour de cette position d'équilibre.

Description :
Modélisation dynamique et développement d'une loi de commande sous MATLAB/Simulink.
Conception 3D, assemblage et mise en service du système.
Conception électronique : schéma de puissance, commande PWM, encodeur et ESP32.
